# Sahay Web

Local-first web companion for Sahay, a women's safety prototype.

This repository is separate from [Sahay-Safety-App](https://github.com/AyushAP-007/Sahay-Safety-App). That older project is unchanged.

The app runs in a phone-style preview. Profile, contacts, events, and settings stay in the browser. There is no cloud account, no real SMS or calls, and no physical locket. Safe Journey uses OpenStreetMap walking paths and scores them by nearby police, hospitals, and pharmacies. That score is a rule list, not a crime-trained model.

```bash
npm install
npm run dev
```
